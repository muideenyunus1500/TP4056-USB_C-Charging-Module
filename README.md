TP4056 USB-C Charging Module
A compact USB-C Li-ion battery charging and protection module designed in **KiCad 9**.
 Overview
This project implements a TP4056-based charging circuit for a single-cell Li-ion battery with battery protection using the DW01A protection IC and FS8205A dual MOSFET.

Features
- USB Type-C input
- TP4056 Li-ion charging IC
- DW01A battery protection
- FS8205A dual MOSFET protection
- Charging status LEDs
- Compact 2-layer PCB
- Designed in KiCad 9
